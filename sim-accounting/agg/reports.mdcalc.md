# 计算器规则

## 版本
0.1

## 功能简介
sim-accounting 三大报表计算器。输入选定项目（selected_proj_id）的全部 journal 分录，
按 account_code 分列汇总各科目余额（符号化自然方向记账：资产记借方/负债权益记贷方，
减少为负，已合并入单列），再组装三大报表：项目资产负债表、项目利润表、项目现金流表。

> 本文件采用紧凑录入（1D 范围 + seq + grid），将原逐格写法的 203 ops 压缩到 63 ops，
> `# 结果` 表与逐格版逐格一致。

## 列布局（data 区，row 1 表头，row 2+ 数据）
- A: journal_id（仅展示，不参与计算）
- B: event_type（事件类型，展示+现金流归类用）
- C: journal_time（展示，不参与计算）
- 资产科目（account_side=cr，变动记借方=金额本体）：
  - D: 1001 项目经费
  - E: 1002 未结算工时
  - F: 1003 已结算工时
  - G: 1004 合同未出账款
  - H: 1005 应收账款
- 负债科目（account_side=dr）：
  - I: 2001 应付账款
  - J: 2002 应付工时
- 权益科目（account_side=dr）：
  - K: 3001 项目预算
  - L: 3002 预发TUP
  - M: 3003 上期滚存毛利
  - N: 3004 当期毛利
- 费用辅助列（利润表/现金流归类用，仅费用计入事件填写，其他事件留空）：
  - O: 项目相关费用额（路径①付现，借1001↓/贷3004毛利↓；动经费算经营现金流）
  - P: 项目不相关费用额（路径②挂账，借3001↓/贷2001应付↑；不动经费不算现金流）
> 每笔分录一行，只在对应科目列填金额（已合并 debit/credit 为带符号金额），其余列留空。费用计入事件额外在 O 或 P 列填该笔费用额（正数，供利润表费用行与现金流费用支出行求和）。

## 报表组装（结果区）
1. **科目余额行**：逐列 SUM(data 区) = 该科目期末余额。
2. **资产负债表**：资产合计 = Σ(D:H)；负债合计 = Σ(I:J)；权益合计 = Σ(K:N)；
   校验：资产合计 = 负债合计 + 权益合计。
3. **利润表**（方案A：人工成本/费用为管理会计展示项，人工成本不入账面；费用真实入账）：
   - 营业收入 = Σ外部结算对外价金额（取 2002 应付工时抵销额的绝对值，已在账面）
   - 人工成本 = Σ外部结算工时量 × 人工费率(120/h)；工时量 = 内部价金额/150（从账面反推）
   - 费用 = Σ(O列项目相关费用额) + Σ(P列项目不相关费用额)；O=路径①(借1001↓/贷3004↓付现)，P=路径②(借3001↓/贷2001↑挂账)
   - 净利润 = 营业收入 − 人工成本 − 费用
   - 账面对照：当期毛利(3004)=对外价−内部价−项目相关费用(O列，路径①减毛利)；净利润−当期毛利 = 内部价−人工成本−项目不相关费用(P列)
   （注：人工费率120/h=内部价150的80%，预留30/h管理摊销与毛利空间；人工成本在利润表展示不入账面；费用双路径真实入账，路径①减毛利付现、路径②走权益转移挂账不碰毛利）
4. **现金流表**（按事件类型归类，以项目经费 D 列净变动为锚的间接法简化）：
   - 经营活动：日清(-D)+费用支出(-D,仅路径①项目相关费用付现)+内部结算(不动)+外部结算(不动)+出账(不动)+回款(+D)
     → 经营现金流 = Σ(日清 D) + Σ(项目相关费用 O列取负) + Σ(回款 D 变动)
   - 筹资活动：立项(+D 注资)+ TUP发放(不动经费) → 筹资现金流 = Σ(立项 D 变动)
   - 投资活动：本系统无投资活动 → 0
   - 现金净增 = 经营+筹资+投资；应 = D 列余额变化（注资+回款−日清消耗−项目相关费用付现）

## 使用流程
1. 切换选定项目时：edit_file 重写 data 区（把该项目分录按科目分列填入 row 2+，费用计入事件填 O/P 列）
2. edit_file 调整余额行/报表行的 SUM 范围（对齐 data 区末行）
3. bash 运行 `mdcalc sim-accounting/agg/reports.mdcalc.md` 求值
4. read_file 读取 `# 结果` 表，作为三大 agg 报表的数据来源

## 紧凑录入说明（对比原逐格写法：203 ops → 63 ops）
- 表头 A1:P1：1 个 1D 行范围 data op（原 16 个逐格 op）
- A 列 journal_id：1 个 seq op（原 32 个逐格 op）
- B 列 event_type、C 列 journal_time：各 1 个 1D 列范围 data op（原各 32 个逐格 op）
- 金额稀疏块 D2:P33：1 个 grid op，null 跳过空单元格（原约 33 个逐格 data op）
- 其余为 func/报表 label，与逐格版相同
