# 计算器规则

## 版本
0.1

## 功能简介
`grid` op 稀疏 2D 录入示例。展示三层紧凑录入：表头一行一个 op（1D 行范围）、
id 列用 seq、稀疏金额块用一个 grid op（null 跳过空单元格）。对比等价的逐格 data
写法，ops 数量从 ~20 降到 5。row 1 表头，row 2+ 数据。

## 使用流程
1. edit_file 追加 op
2. bash `mdcalc <file>`
3. read_file 读 # 结果

# 操作记录

```js
const ops = [
  // ===== 表头一行一个 op（1D 行范围，左到右）=====
  {op:'data', area:'A1:D1', values:['编号','事件','科目','金额']},

  // ===== 编号列用 seq（4 个递增 id 一个 op）=====
  {op:'seq', area:'A2:A5', from:121, to:124, step:1},

  // ===== 事件列用 1D 范围（4 个值一个 op）=====
  {op:'data', area:'B2:B5', values:['合同签订','出账','回款','费用计入']},

  // ===== 稀疏金额块用一个 grid op（科目+金额两列，每行只填一科）=====
  // C 列=科目代码（文本），D 列=金额（数字）；每行只动其中一个，另一个 null 跳过
  {op:'grid', area:'C2:D5', values:[
    [null,      600000],   // row2: 仅 D2=600000（合同金额）
    ['1004',    -180000],  // row3: C3='1004', D3=-180000（出账）
    [null,      180000],   // row4: 仅 D4=180000（回款）
    ['1001',    -8000]     // row5: C5='1001', D5=-8000（费用）
  ]},

  // ===== 汇总：金额合计（仅非空单元格参与 SUM）=====
  {op:'func', area:'D7', values:['ROUND(SUM(D2:D5),2)']}
]
```
